# 坦克大战 (Tank Battle)

一个纯 HTML5 Canvas 实现的经典坦克大战小游戏，单文件即可运行，无需任何依赖。

## 玩法

- **方向键 / WASD**：移动坦克
- **空格**：发射子弹
- **Enter**：开始 / 重新开始
- 移动端（手机）会自动显示触屏按钮

## 游戏规则

- 消灭所有敌方坦克即可通关进入下一关，每关敌人数量递增。
- 保护你的基地（地图下方中央的金星），基地被摧毁则游戏结束。
- 你有 3 条命，被击中会重生并短暂无敌。
- 棕色砖墙可以被子弹打穿，灰色钢墙无法破坏。

## 运行

直接用浏览器打开 `index.html` 即可，也可以在线体验（GitHub Pages）。

## 技术栈

- HTML5 Canvas
- 原生 JavaScript（无框架、无依赖）
